
# Retail Sales Data Analysis Using Python

## Project Overview
This project focuses on analyzing retail sales transaction data using Python to identify sales trends, customer purchasing patterns, and product category performance.

## Objectives
- Analyze revenue across different product categories.
- Study customer demographics, including age and gender.
- Identify monthly sales trends.
- Create visualizations to understand retail business performance.
- Generate meaningful insights from sales data.

## Dataset
The dataset contains 1,001 transaction records with information about transaction dates, customer demographics, product categories, quantities, prices, and total amounts.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow
1. Load the dataset into Python.
2. Inspect and clean the data.
3. Prepare additional features, including age groups, months, and years.
4. Perform exploratory data analysis.
5. Create charts and visualizations.
6. Interpret the findings.

## Key Findings
- Electronics generated the highest revenue among the three product categories.
- May recorded the highest monthly sales in the analyzed dataset.
- Sales patterns were examined by gender, age group, and product category.

- `retail_sales_analysis_report.pdf` — Detailed project report.

This project demonstrates how Python-based data analysis can help identify sales trends and generate useful insights from retail transaction data.
